## 三种依据不可混同 / Three distinct kinds of authority

- **发布代码 / Released code:** 可按固定提交验证的实际算子、排序、阈值、随机调用与循环。遵循它可建立code-reference，不等于恢复作者当年的全部运行。 / Operators, ordering, thresholds, random calls and loops at a fixed commit define a code reference, not the complete historical execution.
- **论文描述 / Paper-described method:** 原始ACE、TCAV、HU-MCD正文/补充各有不同层次的描述；遗漏的ID、依赖版本、seed不能补成“作者设置”。 / Paper descriptions do not supply missing IDs, dependency versions or seeds.
- **操作选择 / Operational choices:** 本项目清单、RGB资格、种子、权重锁定、batch、缓存身份契约；全部显式记录。改变负样本面板、梯度目标、SLIC区域或统计规则则属于科研协议变体。 / Project manifests, RGB eligibility, seeds, weight locks, batches and cache contracts must be explicit. Changes to negative panels, gradient objective, SLIC regions or statistical rules define scientific variants.

## 20次究竟重复什么 / What the20 repeats actually mean

**已确认的是代码，不是论文私有运行。** 对每个概念c（包括随机对照），令完整、经加载和零特征处理后的随机特征池为P。第1轮抽得N(c,1)，大小50；第2至20轮满足 **set N(c,r)=set N(c,1)**，只是顺序可能不同。外层继续给下一个概念传P，故不同概念不保证共享N。随机对照正例Q从P取50，Q与对照负例N(control,1)没有排交集规则。依据为ACE-P03/P04所列源码。

**This establishes code behavior, not the paper’s private run.** For each concept c, including the random control, start from the complete eligible feature pool P. The first round selects50 identities N(c,1). Rounds2–20 satisfy **set N(c,r)=set N(c,1)** while their order may vary. The outer loop passes P afresh to each concept. Control positives Q also come from P, without an exclusion against N(control,1). See ACE-P03/P04.

同一50条负例的排列可以改变固定索引80/20 split中的样本身份；SGD默认也随机。因此不能反过来断言“20次CAV全相同”。但随机总体间变异没有被20组新负样本刻画，概念和control的第r项也没有共同负样本组作为配对单位。p值只能作为被审计的发布代码产物；不把它包装成充分校准的独立重复检验。原始ACE共同random500_r让配对单位更明确，但仍共享概念正例、梯度图片，也没有公开证明随机文件夹互不重叠。 [SGD官方参数](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.SGDClassifier.html)；[SciPy配对检验定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_rel.html)

Permuting the same50 negatives can change identities in the fixed-index80/20 split; SGD also has a stochastic default. Therefore **identical negative sets do not imply identical CAVs**. However,20 new negative populations are not represented, and concept/control entry r is not matched by a common negative set. Treat p-values as audited code outputs, not proven calibrated independent-repeat inference. Original ACE’s common random500_r makes pairing clearer, but it still shares concept positives and gradient images and does not prove folder disjointness. [SGD parameters](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.SGDClassifier.html); [paired-test definition](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_rel.html)

## CE核查与不能默认进行的“修正” / CE verification and changes that are not automatic fixes

TCAV论文§3.3–3.5定义目标logit方向导数、正符号比例以及对0.5的检验；原始ACE公开代码则使用wrapper返回的梯度和负符号比例。2019/2021公开TCAV wrapper将名为prediction的端点送入CE；InceptionV3端点表区分prediction=softmax与logit=softmax/logits，故不能称其与HU对原始输出logits求CE严格等价。论文/README文字与可见实现必须分开记录。 [TCAV论文，PDF第4页](https://proceedings.mlr.press/v80/kim18d/kim18d.pdf)；源码见ACE-P06。

TCAV paper §§3.3–3.5 specifies target-logit directional derivatives, a positive-sign fraction and a test against0.5. Original ACE code uses wrapper-provided gradients and a negative-sign fraction. Inspected TCAV wrappers pass a prediction endpoint to CE, while the InceptionV3 endpoint map separately names softmax predictions and logits. They cannot be declared identical to HU’s CE on classifier logits. Keep textual descriptions distinct from visible implementations. [TCAV paper, PDF page4](https://proceedings.mlr.press/v80/kim18d/kim18d.pdf); code in ACE-P06.

**推导 / Derivation:** 对global_pool特征h及线性头z=Wh+b，HU平均CE梯度为 `(Wᵀ softmax(z) − w_y)/B`；目标logit梯度为 `w_y`，与图片无关。改变batch的正比例因子理论上不改符号，但浮点/TF32差异不保证逐位一致。直接改CE→logit会改变科学问题，并使这个层的逐图符号分数退化；不推荐作为无条件“bug修复”。这里是解析推导，没有新增预测或梯度计算。

For features h at global_pool and a linear head z=Wh+b, the mean-CE gradient is `(Wᵀ softmax(z) − w_y)/B`, whereas the target-logit gradient is `w_y`, independent of the image. Positive batch scaling alone preserves signs analytically, but floating-point/TF32 differences need not be bitwise identical. CE→logit changes the scientific question and degenerates image-wise sign scoring at this layer. This is an analytic derivation, not a new gradient/model run.

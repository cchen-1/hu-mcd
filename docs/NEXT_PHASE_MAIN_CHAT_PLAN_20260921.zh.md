## 1. 研究目标、会议一致性与范围

### A：固定系统对最终输入区域变化的敏感性

问题：图像、分类器和已学习概念基固定时，区域轻微缩小／扩张后，特征、概念分配和原概念得分是否变化？

这是会议选择的第一项受控实验。保留原始图片，先精确重建原有效输入掩码，在其最后一次缩放／二值化之后、实际传入masked CNN之前施加扰动。不重新触发原条件腐蚀。不运行SAM，不重新发现概念。

能支持：指定图像、概念基、模型及扰动条件下的区域敏感性；与面积、原分配间隔、零特征等的关系。

不能支持：真实分割边界准确率、SAM生成稳健性、重新拟合的概念稳定性、整套方法对所有数据／种子的稳健性、人类可理解性或因果医学解释。

### B：医学方法迁移及外部临床征象关联

主线恢复会议方案，不能被旧准备文档的方便实施路线替代：

1. 核实DermaMNIST-C数据发布身份，获得可追溯的标准医学ResNet50，或经批准自行从ImageNet初始化微调。
2. 在源域一个诊断类别上执行HU-MCD概念发现。
3. 冻结分类器、概念基、分割／预处理与分析协议。
4. 源域内部留出评价用于定位问题；Derm7pt皮肤镜图像与七项征象标签用于外部关联评价。

“迁移”指将方法应用于医学模型并学习医学概念，不是复用ImageNet概念基。ResNet18只保留为需明确选择的备选；不因已下载就默认采用。源域内部70张melanoma测试图片（若审核后适用）不能替代Derm7pt外部评价。

能支持：特定源域／分类器／目标类别上，发现概念在外部皮肤镜数据中是否仍出现，以及它们与病例级临床征象标签的关联。

不能支持：普遍的医学迁移能力、像素级征象定位准确率（除非另获适合的标注）、专家认可的概念语义、临床效用或因果依赖。疾病预测、征象关联、数值完整性、人工解释必须分别呈现。

## 6. 工作线A：可执行协议与步骤

### A0：先冻结协议，不偷换分析定义

推荐提交用户一次选择的组合：10类原固定验证全部500图；identity、erosion r1/r2、dilation r1/r2；最终真实输入网格，离散圆盘`dx²+dy²<=r²`，图外0且截断，不填洞／去碎片，各条件独立生成。保留原mask polarity（1为选中区域）、model masking mode与精度。不要把feature-map mask或乘灰背景后的RGB图当最终input mask。

输入网格以每类接受模型配置实际值为准，不从“ResNet通常224”推测。若不是统一尺寸，协议须明确是否分组，不静默重采样。每个原region ID贯穿所有条件，保留original image ID、region index、raw/effective mask hash、基线basis身份。

主指标（新增研究分析定义，待批准）：对图片i，令Vi为基线掩码非空且特征有限、非零、可按原规则分配的区域。`R_i = 扰动后仍有效且保留原概念/OC的区域数 / |Vi|`。空／零结果留在分母，不计为保留；`|Vi|=0`为不可评价，不填0。类内平均R_i为主，十类宏平均为总体；同时报告基线赢家为学习概念与OC的分组，避免OC稳定掩盖学习概念变化。

另报：两侧均有效时的条件一致率及分母；全部原区域的空／零／非有限／缺失状态；原无效→有效；学习概念→其他学习概念／OC与OC→学习概念；每图完整计数。原全零特征在benchmark中可能argmax到C0的历史行为可单独保存为legacy字段，不能作有效概念或静默更改旧结果。这里的有效性定义是本次敏感性分析新增协议，不是假称原benchmark已经如此处理。

建议不确定性：类内按图片配对bootstrap 2,000次，分析seed20260921；同图所有片段和条件一起重采样，报告95%区间和实际样本数。该次数／seed是可复现的操作选择而非论文规定，待批准；不确定性只覆盖当前图像抽样，不覆盖训练／拟合种子。面积／间隔分层边界在看扰动结果前冻结；可用基线分位数并保存精确切点，不按效果重新选bin。

### A1：实现最小隔离路径

- 复用实际接受版本的原图处理、条件腐蚀、resize、二值化，构建identity有效mask；只增加一个显式的最终mask干预入口。不重写整个Dataset或masked CNN。
- 原代码当前参考：`classes.py:188–252`；最终二值化之后插入干预，已接受环境源码和依赖版本优先于当前HEAD推测。
- 精确绑定每类basis／补空间、分配与norm配置。用原斜分解，不改成独立正交投影；不混发现、benchmark的不同归一化／打分路径。若目标分配定义不能唯一对应现有缓存，列出差别询问用户，不按看起来更稳定的规则选。
- 原batch8／精度作为复用起点，以实际接受记录为准。保留确定性region顺序与批次身份；现有代码有batch相关归一化，不能在跳过空区域后无记录改变比较尺度。记录每批实际ID及归一化分母，说明可比性；遇科学歧义先停止该路径。
- 只增加与新路径相关的测试：identity位级mask匹配、简单几何的极性／边界／空mask、同ID映射、有限有效向量按原规则分配。不要重新跑SAM probe或覆盖已有数学测试套件。

### A2：一次正式作业中的首阶段控制

- identity mask与基线重建应精确匹配；有效特征／得分／分配在原接受精度容差内一致。沿用有证据的原容差，新增容差需说明浮点来源，不在失败后放宽到通过。
- 原零特征逐项核对；掩码非空但零特征是记录的观测，不自动认为损坏。原来有效却出现无法解释的非有限值／ID错位则中止。
- 可在一份正式作业中先运行identity并接受后顺序运行4个干预；也可每类独立有同样首阶段门槛。控制失败不得继续生成可被误认为有效的扰动结果。
- 保存阶段状态和失败证据；不自动换precision、device、库版本、模型或checkpoint来兜底。

### A3：干预与记录

- 初始所有5,687个区域均进入账本；4个干预加identity约28,435个region-condition记录，实际CNN执行数因空mask策略而不同，提交计划必须区分。
- 推荐空mask记为`EMPTY_AFTER_INTERVENTION`并不送入不支持空输入的CNN；feature／score记缺失而非伪造全零，保留计数和原因。非空零特征由实际模型结果确定。该规则与批次可比性须一起冻结。
- 保存每区域mask几何（基线面积、当前面积、对称差、IoU及定义）、特征、完整概念／OC得分、原概念对最强竞争者的间隔、原／新分配、状态和失败原因。
- 记录原概念的间隔，不只保存新赢家的间隔；否则切换后高margin会掩盖原概念已失去优势。
- 不把5个条件拼接后重新归一化，也不改变其他区域以“修复”膨胀重叠或腐蚀空隙。

### A4：验收与展示

- 每原ID应有所有条件的明确状态；缺失不是0；核对实际处理图／region数、权重／basis／输入身份与有限性。
- 类别级主指标、条件一致率、有效分母、几何变化、状态转移和预先定义分层分别呈现。不存在有依据的统一“达到X%就通过robustness”阈值。
- 全部参考原型保留原ID与排序；另用独立展示seed20260921冻结随机成员。诊断例可按预先定义的消失、切换或大特征变化条件选择，列出规则／数量，不冒充总体代表。

### B3：冻结后源域及Derm7pt评价

> 2026-09-22范围更新：R101及S描述性已作为协议获批；医学发现、外部模型推理和后续执行预算仍未授权。 见[集中决策表最新批准](NEXT_PHASE_CURRENT_DECISIONS_20260922.zh-en.md)。其他规则不变。

**外部评价建议：**优先沿用Derm7pt官方test作为确认评价池，按已批准目标诊断映射形成目标类子集；train／validation若用于制定概念—征象对应或汇总规则，明确标为目标域开发材料，不能再合并到最终确认分母。需先只看元数据计数，确认七项征象在目标类中的正负样本是否支持分析；不按模型结果调整子集。

如果官方test目标类太少，向用户提出两个明确替代：①保持官方test并诚实报告宽区间／不可估计项；②使用更大预先冻结的外部探索队列，并放弃“独立确认评价”的说法。不要计算完再切分或选择最好结果。

**标签映射：**DermaMNIST七类和Derm7pt原细类别／分组五类不相同。先公布文字定义、原标签、目标编码与不兼容项。Melanoma各亚型的合并需要明确依据；不把所有miscellaneous都塞进某一源域类。单类研究只需明确该类映射，不应为方便声称七类完全可比。

**分析单位与响应：**病例级征象标签不能复制到该病例每个segment后当成独立标注。每概念先将区域响应按预先确定的规则汇总到病例，再与该病例征象比较。

建议主对话用源域证据提出两类分离的响应：

- 出现／覆盖：例如最终归入该概念的有效区域并集占输入图面积；区域重叠用并集避免重复计数，OC另报。其含义为当前分割和分配下的覆盖，不是纯语义强度；模型输入有效mask对应关系需核实。
- 连续表示响应：使用既有分解定义的概念activation，并明确max或加权聚合、归一化、重叠处理与零区域情况。max可能偏向多片段图，加权可能受区域面积影响；不能根据Derm7pt上哪个相关更强再选。

主响应、次响应及没有有效区域时的定义必须执行前由用户确认；没有材料支持唯一选择时不在程序内默认。覆盖无成员可为真实0；无法提取／缺数据必须为缺失，不混淆。

**关联评价：**保留原七项征象的类别含义，若用原论文的absent／regular／irregular分组需明示；不能全自动二值化。二值且两类存在时可用预定方向的ROC-AUC和效应分布；多类别按预定义对比报告，不把无序标签编码成0/1/2做任意相关。报告患病／标签分布、实际病例数与区间。

概念—征象全矩阵存在多重比较：推荐第一轮以完整探索性效应矩阵、区间和所有缺失分母为主；如需显著性检验，预先冻结检验家族、方向、校正和独立单位，不只展示最小p值。若从目标域开发集挑选语义配对，需在独立test确认；若test上探索命名，则明确没有独立确认。不能对负向关系翻转分数后当作预先正向验证。

只在目标诊断类内分析可减少疾病标签共变的混淆，但可能正负样本不足、范围受限；跨诊断分析是不同范围，需要控制／分层诊断，不能无声扩大。影像／病例级关联不证明区域定位或模型因果依赖。

### B4：视觉、临床解释及暂不执行的扩展

- 稳定ID包含`HU-MCD-medical-数据版本-诊断类-概念ID`；同数值编号不默认对应ImageNet概念。初始cluster与最终train／source-test／Derm7pt成员分开。
- 展示全部学习概念和单独OC；原型、固定随机与诊断示例分开；保留皮肤／毛发／黑边／背景等内容，不自动当噪声删除。
- 每例带病例、图像、区域ID，实际征象标签与来源，selected region、overlay、selected-only；AI描述标待确认，专业审阅未做就显示未审阅。
- 首轮核心是源域／外部关联，不自动新增医学C-Insertion/C-Deletion、ACE/MCD医学基线、医学mask敏感性、SAM替代或多类别扩展。这些都需要独立配置／预算。
- 本次找到的原Derm7pt标准资料支持病例级征象，尚未确认像素真值。不能用SAM自身掩码作ground truth；即便后续有病灶轮廓，也不能用它代替色素网络／条纹的空间标注。

## 9. Fail early：暴露问题而不是造一层层fallback

| 情况 | 处理 | 原因 |
|---|---|---|
| 输入ID／mask方向／特征顺序／权重／basis hash不符 | 立即停止受影响阶段，保留现场并报告 | 此时差异无法作科学解释 |
| identity对照无法复现，或新出现未解释非有限值 | 失败退出；分离数值／代码／数据因素，不先放宽容差 | 不让新路径错误被误判为敏感性 |
| 模型架构／类别映射／预处理不明 | 暂停该方法或阶段，提供实际选择 | 不用默认ResNet18、猜mean/std或错误类别兜底 |
| 可确认跨split泄漏或外部身份不清 | 暂停受影响的外部独立性结论／任务 | 不自动删图改split或宣称完全独立 |
| 已声明扰动导致mask变空／非空零特征 | 保留ID、状态和主指标分母；作为结果 | 这是预期研究结果，不是全项目停工原因 |
| 无概念、低覆盖、关联弱或负、误分类 | 原样保存与解释；若形成无法继续的输出结构，停止依赖阶段 | 不调参“救结果”，不强制产生漂亮图 |
| SSC早停／收敛警告等潜在科学影响 | 保存优化状态、受影响概念及证据；标明数值一致不等于充分收敛，按影响暂停或限定解释 | 来源于原仓库也不能忽略；不能一条警告就断言论文错误 |
| 明确不改变科学含义的日志／路径／本地渲染错误 | 最小修复、记录前后版本，继续不受影响工作 | 不必把小工程问题变成全项目审批流程 |
| 包／环境不兼容 | 显式错误，不自动升级依赖或切换算法；先给证据和修复范围 | 新环境可能改变方法行为 |

禁止通用`except: continue`吞错、失败区域填0当正常结果、缺失图静默替换、加载失败换checkpoint、GPU不足换精度、缓存不匹配仍reuse、重新计算直到得到预期概念数。预期空／零状态的显式处理是研究协议，不是兜底掩盖；三者必须区分。

仅保留必要且有科学目的的检查：输入身份、identity一致性、mask／feature映射、有限值／重构、完整计数、缓存契约；复用已验收数学检查。局部异常只阻塞其依赖链，不阻塞另一条独立线。
